# ReDash 控制面架构与当前实现边界

本文件记录当前代码的能力及尚未交付的部分，不再将路线图视为验收结果。安全修复、配置迁移与复现测试见 [控制面安全协议与迁移](CONTROL_PLANE_SECURITY.md)。

## 数据与信任边界

- Agent 通过出站 WebSocket 向 Hub 注册。Hub 从本机 `agent_enrollments.json` 读取每个节点独立的 token 和客户端可信公钥。未知节点、无效 token、不同的客户端公钥和并发重复注册均拒绝。
- Agent 的节点 ID 绑定连接实例。遥测、动作结果和终端帧不能声明属于其他节点或其他连接。
- 终端协议 v2 使用两端独立的 Ed25519 身份。客户端公钥预置在 Agent 上，Agent 公钥由本地配发流程固定在桌面 `agent_keys.json` 中，不能从 Hub 的未验证响应取得。
- 每次终端连接使用操作系统安全随机源生成 X25519 临时密钥、随机握手 nonce 和新会话 ID。双方签名绑定版本、节点、会话、时间、nonce 和临时公钥。HKDF-SHA256 派生独立收发密钥，AES-256-GCM 认证方向、会话和序号。重复、倒退、篡改、错误方向的帧均拒绝。
- 创建、输入、resize、关闭都通过加密控制帧完成。握手超时或校验失败会终止连接，无匿名 shell 或明文降级路径。只有首个加密 Open 才分配 PTY。
- Hub 可以看到终端连接元数据，并能中断服务，但在可信客户端与 Agent 密钥未泄露的前提下不能解密终端内容。遥测、签名治理动作及其结果仍对 Hub 可见。原有 SSH/SFTP 网关仍持有 SSH 连接能力，不能把它描述成终端协议 v2 的盲中继。

## 终端与发现

Agent 使用系统 PTY 和控制终端启动交互 shell；resize 使用终端 ioctl，Ctrl-C 经终端驱动送给前台进程组。会话上限为 32，未发送 Open 的握手会话约 10 秒过期，未收到客户端活动的终端约 10 分钟过期，断连会清理对应 PTY 和子进程。

当前重连建立新会话，**不恢复旧 shell**。共享 RingBuffer 组件仍保留，自动恢复协议、跨设备续接和断线保活尚未交付。之前宣称已完成的 Bridge 自动恢复不成立。

局域网发现是自定义 UDP 组播/广播 beacon（239.255.77.88:8765），不是 mDNS。beacon 只提供候选地址，终端仍需要验证预先固定的 Agent 身份。桌面可以竞速 LAN 与 Hub；胜出路径完成认证后才发送 Open，因此失败或取消的竞速连接不启动 shell。LAN 终端输出只发送到该 LAN 连接，Hub 遥测与心跳仍继续，不能宣称全部 Hub 流量为零。没有给出未经测量的延迟或连通率保证。

## 监控与告警

Linux/macOS Agent 使用系统指标库读取实际 CPU、内存、根文件系统和网卡计数。遥测含每项采样有效性，首次 CPU/网络采样和缺失指标不作为正常零值参与阈值评估；桌面显示 `--`。

Hub 在连接断开后保留节点和最后遥测，标记 Offline。心跳超过 15 秒标记 Stale，超过 30 秒标记 Offline。旧连接不能删除或更新重连后的状态。注册凭据保存在配置文件；在线状态和最后遥测是进程内状态，尚未实现跨 Hub 重启的历史存储。

Agent-only 遥测和 SSH 探针使用同一资源阈值评估与 webhook 分发逻辑。有效恢复会解除 Agent 资源告警冷却，持续超限抑制重复发送。离线告警遵守 `alert_notify_offline`，失败发送允许重试。

## 产品与交付状态

- 桌面已有节点展示、签名治理、端口数字编辑及通过 LAN/Hub 的加密终端。远程 Hub 可通过 `REDASH_HUB_URL` 配置，尚无持久化设置页面。
- 接入弹窗生成节点 ID、独立 token、Agent 身份密钥，提供 Hub 注册配置和安装命令。Hub 注册文件需要由操作员合并；复制安装命令会在本机固定该节点的 Agent 公钥。
- 安装器的 systemd 凭据保存在权限 600 的环境文件；Compose 要求显式 token。没有可信客户端公钥时只允许遥测；没有 Agent 身份私钥时终端禁用。
- Agent 和桌面 WebSocket 已启用 Rustls/WebPKI TLS 校验。公网部署应使用 WSS，TLS 终止仍由部署环境配置。
- Web/WASM 共享模型可编译；完整的控制面管理界面与终端交互尚未达到桌面功能对等。
- 配对 URI 和二维码编解码组件仍是基础组件。没有移动端工程或配对授权交换，桌面接入弹窗不再将二维码描述为已完成的移动端授权。
- 本地回归测试不能替代 Linux/musl 发布构建、安装部署、真实桌面 GUI 或移动端验收。
